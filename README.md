# Bellabeat Smart Device Usage Analysis

This case study analyzes Fitbit smart device usage data to identify trends in activity, sleep, and wellness behavior. Insights from the analysis were used to develop marketing recommendations for Bellabeat’s Leaf wellness tracker.

## Tools Used
- R
- RStudio
- tidyverse
- ggplot2
- lubridate

## Files
- `bellabeat_case_study.Rmd` — source analysis file
- `bellabeat_case_study.html` — final report

## Data Source
FitBit Fitness Tracker Data (Kaggle)
